# הסרת סיסמה מ-PDF

כלי שרץ כולו בדפדפן: מעלים קובץ PDF נעול (או כמה קבצים עם אותה סיסמה) ומורידים עותק בלי סיסמה, או קובץ אחד מאוחד.
הקבצים לא נשלחים לשום שרת. מבוסס על [qpdf](https://github.com/qpdf/qpdf) שקומפל ל-WebAssembly ([qpdf-wasm](https://github.com/neslinesli93/qpdf-wasm)), ותאריכי המסמכים נקראים עם [pdf.js](https://github.com/mozilla/pdf.js).

האתר: https://tomerglaicher.github.io/pdf-unlock/
